# Collection Mask Exporter (CMask)

CMask is a Blender Extension for exporting stable Collection Color IDs,
per-Collection masks, Multilayer OpenEXR, Collection Cryptomatte, reports, and
Photoshop handoff files.

Version: 0.8.0

Formally supported Blender versions:

- Blender 4.5.x
- Blender 5.0.x
- Blender 5.2.x

Install this ZIP through **Edit > Preferences > Extensions > Install from
Disk**, then restart Blender after replacing an older version.
